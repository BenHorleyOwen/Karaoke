# Karaoke
a karaoke service to attach to my [Music Server](https://github.com/BenHorleyOwen/Music-Server) compose stack.

## .env structure
- NAVIDROME_USER = (index.js defaults to Karaoke)
- NAVIDROME_PASS = (index.js defaults to Karaoke)
on your navidrome instance go to `/app/#/user/create` and make a karaoke account.
